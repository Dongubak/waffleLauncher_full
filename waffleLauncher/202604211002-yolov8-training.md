# YOLOv8 모델 학습 — WaffleCar 연동

## 개요

WaffleCar 제어에 YOLOv8 객체 탐지 모델을 적용한다.
기존 YOLOv3(`cv2.dnn`) + Keras 분류 모델을 YOLOv8로 대체한다.

- **목적**: 차량 이미지에서 객체(신호, 장애물 등) 탐지 → 자율주행 명령 생성
- **입력 해상도**: 640×360 (카메라 기본), 추론용은 640×640 권장
- **프레임워크**: Ultralytics YOLOv8

## 데이터 수집 (waffleLauncher 활용)

### 데이터 녹화
1. waffleLauncher 실행
2. **시뮬레이션 탭** → "시뮬레이션 데이터 녹화" 버튼
3. 와플카를 수동 조작하면서 이미지 수집
4. `savedImage/` 폴더에 `<frame>-<lidar>.jpg` 형식으로 저장

파일명 구조:
```
0001-0120.jpg   → 1번 프레임, LiDAR 120mm
0002-0150.jpg   → 2번 프레임, LiDAR 150mm
```

### 레이블링
수집된 이미지에 어노테이션 작업이 필요하다.

**도구 (선택 사항):**

| 도구 | 특징 |
|---|---|
| [Roboflow](https://roboflow.com) | 웹 기반, YOLO 포맷 내보내기 지원 |
| [LabelImg](https://github.com/HumanSignal/labelImg) | 로컬 실행, YOLO TXT 포맷 |
| [CVAT](https://www.cvat.ai) | 팀 협업, 다양한 포맷 |

**YOLO 레이블 포맷 (TXT):**
```
<class_id> <x_center> <y_center> <width> <height>
# 모두 0~1 정규화된 값
```

## 모델 학습

### 기본 학습

```python
from ultralytics import YOLO

# 사전학습 모델 로드 (YOLOv8n: 가장 가벼운 버전)
model = YOLO('yolov8n.pt')

# 학습 실행
results = model.train(
    data='dataset/data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0,          # GPU 사용 (CPU는 'cpu')
    project='runs/train',
    name='wafflecar_v1'
)
```

### 모델 크기 선택

| 모델 | 파라미터 | 추론 속도 | 권장 용도 |
|---|---|---|---|
| YOLOv8n | 3.2M | 가장 빠름 | 임베디드 / 실시간 |
| YOLOv8s | 11.2M | 빠름 | PC 실시간 |
| YOLOv8m | 25.9M | 보통 | 정확도 우선 |
| YOLOv8l | 43.7M | 느림 | 고정밀 |

> WaffleCar는 PC에서 추론하므로 YOLOv8s 권장

### 주요 학습 파라미터

| 파라미터 | 권장값 | 설명 |
|---|---|---|
| `epochs` | 100~300 | 에폭 수 |
| `imgsz` | 640 | 입력 이미지 크기 |
| `batch` | 16 | 배치 크기 (GPU 메모리에 따라 조정) |
| `lr0` | 0.01 | 초기 학습률 |
| `augment` | True | 데이터 증강 활성화 |
| `patience` | 50 | Early stopping 에폭 수 |

## algorithm.py 연동

### 기존 Keras → YOLOv8 교체

```python
from ultralytics import YOLO
from wafflecarUtil import *

def autoDrive_algorithm(original_img, canny_img,
                        H1LD, H1RD, H2LD, H2RD, H3LD, H3RD,
                        V1D, V2D, V3D, V4D, V5D, V6D, V7D,
                        leftLane, rightLane, frontLane,
                        LiDAR, prevComm, status):
    command = prevComm

    if status == 1:  # 초기화
        model = YOLO('runs/train/wafflecar_v1/weights/best.pt')
        status = [model]
    else:
        model = status[0]

    # YOLOv8 추론
    results = model(original_img, verbose=False)

    # 가장 높은 confidence 클래스 선택
    command = 'H,F0,F0,150,E'  # 기본: 정지
    if len(results[0].boxes) > 0:
        best = results[0].boxes[results[0].boxes.conf.argmax()]
        cls_name = results[0].names[int(best.cls)]

        if cls_name == 'slow':
            command = 'H,F1,F1,150,E'
        elif cls_name == 'track':
            command = 'H,F3,F3,150,E'
        elif cls_name == 'stop':
            command = 'H,F0,F0,150,E'

    # LiDAR 장애물 회피
    if LiDAR > 0 and LiDAR < 200:
        command = 'H,F0,F0,150,E'

    status = [model]
    return command, status
```

## 데이터 증강 권장사항

WaffleCar 환경 특성상 다음 증강을 적용한다:

| 증강 | 이유 |
|---|---|
| 밝기/대비 조정 | 실내/실외 조명 변화 |
| 좌우 플립 | 좌/우 코너 균형 |
| 노이즈 추가 | 카메라 노이즈 시뮬레이션 |
| 모션 블러 | 주행 중 블러 시뮬레이션 |
| 크롭 | 다양한 거리에서의 객체 크기 |

```python
# data.yaml에 추가 또는 train() 파라미터로 전달
model.train(
    ...
    hsv_h=0.015,    # Hue 조정
    hsv_s=0.7,      # Saturation
    hsv_v=0.4,      # Value (밝기)
    fliplr=0.5,     # 좌우 플립 확률
    mosaic=1.0,     # Mosaic 증강
    blur=0.01,      # 블러
)
```
